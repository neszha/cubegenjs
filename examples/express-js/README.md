# About Project

Protecting ExpressJS project with node-protector module CubegenJS.

## Setup 

Install dependencis.
```sh
npm install
```

Run original code.
```sh
node .
```
You can access original program with browser in `http://localhost:3000`

## Build

Build original code to distribution code.
```sh
npx cubegen build
```

Run distribution code in `dist/`.
```sh
cd dist
```
```sh
node .
```
